# BD-CONTROL-DE-AYUDAS-HUMANITARIAS
Base de Datos SQL para Control y Seguimiento a la entrega de ayudas humanitarias ante desastres naturales como un terremoto. La base de datos permite registrar hogares afectados, identificar sus necesidades, recibir donaciones, controlar la disponibilidad de las ayudas y dejar constancia de las entregas de estas.
